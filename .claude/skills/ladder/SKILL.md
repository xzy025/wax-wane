# 连板梯队与情绪

输入：`/ladder [主线关键词] [YYYYMMDD]`。省略日期用最近可得交易日，
披露真实日期及盘中/收盘状态；指定历史日期时核对响应日期。

1. 按[数据契约](../_shared/data-sources.md)市场数据部分取涨停、跌停、炸板池及
   宽度/情绪。核对覆盖与分页，缺失字段不能当 0，不能用最新池冒充历史池。
2. 按连板数统计高度、各级数量和空间龙。指定主线时按有来源的题材关系筛选；
   名称或粗行业只能支持候选归类，不足以确认龙头身份。
3. 结合前一交易日同口径数据判断梯队延续、晋级率与退潮。炸板次数不能代替
   炸板家数或炸板率；没有昨日队列不能声称计算了晋级率。
4. 情绪阶段可用冰点/修复/高潮/退潮描述，给出支持与冲突证据。只读
   `src/agent/tradingPatterns.ts` 中需要的 sentiment 定义，避免全量模式展开。
5. 输出日期/覆盖、核心结论、梯队表、分歧风险及下一交易日观察条件。
   回答局部问题时缩短报告。行情不全则给部分结论并指出哪些判断尚不能成立。

本工作流不自行修改源码或归档。研究与正式交易资格沿用项目边界。
