# 个股综合研究

输入：`/equity <代码或名称> [交易模式id ...]`。

1. 按[数据契约](../_shared/data-sources.md)确认标的和截至时间，独立获取 K线、
   基本面、新闻和相关归档报告。并行取数不改变各来源的日期与质量要求。
2. 读取[方法论](../_shared/methodology.md)相关章节。需要指定交易模式或复现
   应用结果时，再读取 `src/agent/tradingPatterns.ts` 与对应 agent 实现。
3. 分析各维度再综合，保留分歧及缺失信息。简单计数只作项目基线，
   不取代事实权重、行业背景或结构判断。
4. 完整研报按技术面、基本面、消息面、综合评价组织；先交代结论和数据时点。
   用户指定格式时适配。交易计划仅在请求需要且数据足够时给出条件、失效点及
   风险假设；缺少成本不妨碍其余分析。
5. Larry Williams 等额外框架按问题需要使用。无需为复刻应用的编排结构
   强制启动多个代理；委派遵循当前宿主与任务授权。

数据降级应说明对结论的影响。默认在会话交付；落盘或源码修改须属于用户请求。
