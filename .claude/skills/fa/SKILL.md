# 基本面分析

输入：`/fa <代码或名称>`。

1. 按[数据契约](../_shared/data-sources.md)确认标的，取基本面快照；归档深度报告
   在有相关材料时使用，注明报告期、生成日期和时效。
2. 结合行业、盈利质量、增长与估值口径回答问题。需要复现应用分级时读取
   [方法论](../_shared/methodology.md)第三节；固定阈值只是项目启发式。
3. 给出结论与决定性数据；完整报告可列行业、市值、PE/PB/ROE/EPS及历史报告摘要。
   缺失或非适用指标明确标注，不自行补值或仅凭单个阈值断言低估。

数据源以会话实际可用能力为准。本分析不自行修改源码或保存报告；
用户另有交付要求时按请求执行。
