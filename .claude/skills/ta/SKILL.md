# 技术面分析

输入：`/ta <代码或名称> [交易模式id ...]`。按用户问题选择深度。

1. 按[数据契约](../_shared/data-sources.md)确认标的、数据日期、复权和足够的日线。
   名称有歧义时先缩小候选；不能可靠识别则询问代码。缺失数据只限制对应结论。
2. 读取[方法论](../_shared/methodology.md)中相关技术部分；指定交易模式时，只读
   `src/agent/tradingPatterns.ts` 对应定义。未指定可用趋势、结构、量价组织分析，
   无需把每个框架都展开。Larry Williams 仅在用户指定或短线问题需要时使用。
3. 区分已计算事实、模式解释和待确认条件。长均线需足够历史；缺失不能当中性。
4. 先给技术结论，再给决定性证据、支撑阻力、确认/失效条件和数据限制。完整
   技术报告可补充 5/20 日涨跌、区间位置、量比、K线形态和模式匹配。

本工作流分析行情，不自行修改业务源码或持久化报告；用户另外要求时按其范围执行。
