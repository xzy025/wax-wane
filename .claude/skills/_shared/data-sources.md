# 分析技能的数据契约

供 ta、fa、equity、ladder 按需要读取。来源选择依赖当前工具与服务；
过去的“已实测”、免 token 或本机认证失败不代表永久可用性或永久禁用。
本文件不授予额外连接、费用或凭据权限。

## 0. 标的与时点

- A 股使用已确认交易所的6位代码；港股使用5位代码并标明币种。中文名先通过
  可用搜索/市场数据工具解析，有歧义才问用户，不猜代码或市场前缀。
- 固定分析截至时间；核对返回的实际交易日、时区、复权、K线周期与是否已收盘。
  历史问题不能使用接口忽略日期后返回的最新行情。
- 记录来源、获取时间和质量限制。空值、缺失或过期数据不得替换成 0 或中性。
  新闻发布时间与事件发生时间、财报报告期与获取日期分别处理。

## 1. 价格与K线

项目服务可用时读取：
`GET http://localhost:3002/api/stock/kline?code=<代码>&period=101&count=<数量>`。

一般短期分析约60根日线；长均线、周线或结构研究按实际窗口补足历史，
不把60根数据用于计算MA120/250。验证价格/成交量字段、顺序与调整口径。
本地接口字段与支持市场以 `server/routes/mcp.ts`、`server/services/ashare.ts`
和 `server/services/hk.ts` 当前实现为准。

服务不可用时，选择会话中实际提供的市场数据工具或可靠行情来源。
使用前核对工具 schema；不硬编码某个已安装插件的工具名或默认存在的 akshare。

## 2. 基本面

`GET http://localhost:3002/api/stock/fundamentals?code=<代码>`。

按需取 PE/PB/ROE/EPS、市值、行业、利润与收入指标；区分估值日期、财报期、
TTM/静态/动态口径与金额单位。失败可使用可用数据工具及公司/交易所披露；
自算指标要有相应输入，亏损、缺失或不适用时不强行分级。

## 3. 消息面

`GET http://localhost:3002/api/stock/news?code=<代码>&count=10`。

不足时检索公司公告、交易所披露及可用新闻源。保留链接、来源及时间，
区分公告事实、新闻转述与推测。只读标题不能确认具体利好或事件影响。

## 4. 历史深度报告

`GET http://localhost:3002/api/analysis/fundamental/latest?query=<代码或名称>`。

读取 `found,createdAt,reportMd,summary,ageDays,stale` 中实际返回的字段。
归档是历史分析，不能替代当前财报事实；缺失则省略。当前接口见
`server/routes/analysis.ts`。

## 5. 请求、降级与副作用

首次本地请求使用短超时；失败后转向可用替代源，避免每个字段重复探活。
传给 shell 的 URL 整体引用，避免 `&` 被当作命令分隔符。
不为只读分析默认启动服务、安装依赖或强制刷新归档。

切换来源无需额外确认；在结论中简述对时效、覆盖或可比性有实质影响的降级，
无需逐条转述网络错误。限流或认证失败时避免无条件循环重试。
历史本机 tushare token 失败只是线索，以本次授权与认证状态为准。

## 6. 市场与连板

本地接口：`/api/mcp/ashare/limit-pool`、`/api/mcp/ashare/breadth`、
`/api/sentiment`。参数/响应以 `server/routes/mcp.ts` 和相关路由为准。

服务不足时用实际可用市场数据工具；若使用东财池，核对实际 `data.qdate`、
分页总数 `data.tc` 和 `pool[]`，不能假定请求 `date` 被遵守。
涨停池常见字段为名称 `n`、代码 `c`、连板 `lbc`、炸板次数 `zbc`、
行业 `hybk`；按返回 schema 验证，不把字段缺失当0。

涨停、跌停、炸板家数须使用同日同口径数据。晋级率需昨日队列与今日对应结果；
情绪转折需比较历史。单日数量和粗行业不足以确认情绪周期或题材龙头。

## 7. 港股补充

先核实来源支持港股，再解释返回字段和交易规则。价格/市值注明币种；
A/H比较使用有日期的汇率及可比股本口径，不能要求两地显示总市值必然相等。
次新股短历史须显式标注。未经核验的固定汇率或过去源优先级不进入结论。
